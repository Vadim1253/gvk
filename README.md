# GVK — зашифрованное зеркало

Резервный источник актуального списка для Goodini VPN Windows. В репозитории публикуются только зашифрованный каталог активации и зашифрованный облачный список. Открытых адресов и паролей прокси, ключа расшифровки и серверного токена здесь нет.

GitHub Actions проверяет источник каждые 15 минут и коммитит файл `data/mirror.json` только при изменении данных. Есть ручной запуск в Actions. Смена списка в облаке автоматически попадёт в зеркало; обновлять EXE для этого не требуется. При ошибке облака предыдущий файл не перезаписывается. Задания GitHub могут задерживаться; это не гарантия обновления ровно по таймеру. Если публичный репозиторий неактивен 60 дней, GitHub может выключить расписание — тогда его нужно включить снова.

## Настройка

Создайте Actions secret `SOURCE_CONFIG` с JSON-полями `api_url`, `public_key`, `catalog_url`, `read_token`. Токен должен иметь только право чтения. Ключ расшифровки и административные ключи не нужны и не должны добавляться. Значение секрета не публикуется в репозитории и не печатается в журнале.

Файлы находятся в ветке `main`. После настройки секрета запустите workflow `Update encrypted proxy mirror` и убедитесь в успешном создании `data/mirror.json`.

Основной адрес: `https://raw.githubusercontent.com/Vadim1253/gvk/main/data/mirror.json`.
Дополнительный адрес: `https://cdn.jsdelivr.net/gh/Vadim1253/gvk@main/data/mirror.json`.
CDN может отдавать предыдущую версию из кэша. GitHub и CDN нужно проверить из целевой сети без VPN.

Загружайте только содержимое этой папки. Не загружайте родительскую Administration, файлы доступа, ключи или всё приложение.
